# 🚑 지도학습 기반 응급 대응 수준 참고 웹서비스 (AI Triage System)

> **인공지능 기초** 교과목 프로젝트 / 연구 과제  
> 사용자가 증상과 신체 상태를 입력하면 기계학습 분류 모델과 규칙 기반 안전망(Fail-Safe)을 통해 3단계 응급 대응 수준을 안내하는 웹서비스입니다.

---

## 📌 주요 기능 구조

1. **사용자 증상 입력 기능**
   - 증상 유형 (흉통, 호흡곤란, 뇌졸중 의심, 복통, 외상 등)
   - 의식 상태 (명료 / 졸림·혼미 / 의식 저하)
   - 호흡 상태 (정상 / 가쁨 / 심한 호흡 곤란)
   - 통증 정도 (NRS 0~10점 슬라이더)
   - 지속 시간, 연령대, 기저질환 등 모델 훈련 피처 수집

2. **기계학습 기반 증상 분류 기능 (Supervised Learning)**
   - 훈련 데이터 패턴에 따라 3개 클래스 분류:
     - 🚨 **119 신고 및 응급 도움 요청**
     - ⚠️ **응급실(응급의료기관) 신속 방문 권고**
     - ℹ️ **비응급 의료기관 상담 및 외래 진료 고려**
   - 각 클래스별 예측 확률(Confidence %) 및 주요 판단 근거(Feature Impact) 표시

3. **응급 위험 신호 안내 기능 (Red Flag Safety Guardrail)**
   - 의식 저하, 심한 호흡 곤란, 급성 뇌졸중 의심 증상 등 중대 위험 신호 발생 시
   - 머신러닝 추론 결과와 무관하게 **즉각 119 도움 요청 안내를 최우선 노출** (Fail-Safe 안전장치)
   - AI 오분류로 인한 치료 지연 방지

4. **응급실 정보 확인 기능**
   - 지역별 권역/지역응급의료센터 정보 (기관명, 전화번호, 주소, 카카오맵 길찾기)
   - 실제 운영 현황 변동 안내 및 사전 유선 확인 안내

## 🚀 실행 방법

### 방법 1: 즉시 실행 (설치 필요 없음 ⭐ 추천)
프로젝트 폴더 내의 **`index.html` 파일을 더블 클릭**하면 크롬(Chrome), 엣지(Edge) 등 웹 브라우저에서 바로 완벽하게 작동하는 반응형 웹앱이 실행됩니다.
- 별도의 파이썬(Python)이나 라이브러리 설치가 전혀 필요 없습니다.
- 실시간 AI 지도학습 추론, 안전망 필터, 응급실 안내, Chart.js 변수 중요도 분석 차트가 모두 포함되어 있습니다.

### 방법 2: Python / Streamlit 환경에서 실행
Python 환경이 설치되어 있는 경우 아래 명령어로 실행할 수 있습니다:

```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. (선택사항) 모델 학습 및 평가
python train_model.py

# 3. Streamlit 웹앱 실행
streamlit run app_streamlit.py
```

---

## 📁 파일 구성
- `index.html`: 단독 실행 가능한 웹 애플리케이션 (HTML5, Tailwind CSS, Chart.js, JS 지도학습 엔진)
- `app_streamlit.py`: Python Streamlit 기반 대화형 웹 애플리케이션
- `train_model.py`: Scikit-learn Random Forest 모델 학습, 평가 및 `.pkl` 저장 스크립트
- `requirements.txt`: Python 실행에 필요한 패키지 목록
- `README.md`: 프로젝트 안내 문서
